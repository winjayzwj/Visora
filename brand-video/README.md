# Visora Brand Loops

自主自由创作模式下的两支网页循环视频源文件。

## 产品简报

Visora 是面向视觉创作者的本地优先 AI 工作台，核心体验是把提示词、参考图、模型与本地 Agent 组织进一个可编辑画布。视频面向首次到访的创作者，重点表达“创作输入汇聚为连续工作流”，而不是展示任何真实用户数据。

## 设计与执行决策

| 项目 | 决定 |
| --- | --- |
| 使用位置 | 登录页左侧与首页主视觉 |
| 视频形态 | 静音、自动播放、8 秒循环、可在浏览器中内联播放 |
| 品牌 tokens | `#07090e` 画布底色、`#06b6d4` 青蓝、`#00f5d4` 青绿、`#f1fcfa` 暖白、细网格与 16px 节点圆角 |
| 动效性格 | 专业、稳定、工程感；缓入缓出，无镜头抖动、无节拍冲击 |
| 数据口径 | 仅使用 Logo、产品已公开能力词与虚构节点，不采集用户作品、账户、提示词、密钥或实时数据 |
| 声音 | 网页循环视频静音，未加入 BGM 或 SFX |

## 功能与镜头映射

| 页面 | 镜头卡 | 表达 |
| --- | --- | --- |
| 登录页 | `bezier-source-converge-merge` | Reference、Prompt、Model、Agent 沿曲线汇入 Visora Canvas，落成工作流卡片 |
| 首页 | `wall-reveal-moves · wireframe-draw-on` | 蓝图连线与扫描线逐步显形节点，展示从想法到 Canvas 与视觉输出 |

## 分镜

| 视频 | 帧 | 内容 |
| --- | --- | --- |
| 登录页 | 0–30 | 品牌与四类输入稳定出现 |
| 登录页 | 30–150 | 多源曲线连通，输入向 Canvas 汇聚 |
| 登录页 | 150–192 | Canvas Workflow 成形并停留 |
| 登录页 | 192–240 | 平滑回到初始状态，支持循环 |
| 首页 | 0–48 | 品牌与工作流蓝图建立 |
| 首页 | 48–150 | 青绿扫描线与连线逐步显形 |
| 首页 | 150–204 | Prompt、Reference、Canvas、Agent 与输出节点完整可读 |
| 首页 | 204–240 | 平滑收回至蓝图状态，支持循环 |

## 渲染

```bash
cd brand-video
npm install
npm run render:login
npm run render:home
```

网页成片输出到 `web/public/media/`。
