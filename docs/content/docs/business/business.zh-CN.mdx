# 商务合作

如果你希望围绕映序（Visora AI）做商业合作、私有化部署、二次开发或模型渠道接入，可以直接通过邮箱联系项目维护者。

## 适合沟通的方向

- 私有化部署、内网部署和团队版落地。
- 定制画布节点、生成流程、素材管理或后台能力。
- 接入自有 OpenAI 兼容接口、模型渠道或提示词仓库。
- 围绕 AI 图片、视频、文本生成工作流做联合方案。
- 技术支持、交付咨询或联合方案评估。

## 服务与定价包

以下报价为**示例区间**，最终以邮件沟通的范围、工作量与时间为准。请勿直接对外引用示例数字。

### 1. 私有化部署包（标准）

- **适用**：想把 Visora 部署到自有服务器、内网或私有云的个人或团队。
- **交付物**：Docker / 单机部署、反向代理与端口配置、基础品牌与部署文档、一次远程上线协助。
- **不包含**：模型供应商账号、GPU、持续运维、二次开发。
- **报价示例**：¥X,XXX 起（一次性）。待确认。

### 2. 定制开发包（按人天）

- **适用**：需要定制画布节点、生成流程、素材管理、后台能力或模型渠道接入。
- **交付物**：需求评估、工作量报价、分阶段交付、源码与文档。
- **计价示例**：¥X,XXX / 人天；最小起订 X 人天。待确认。
- **典型需求**：接入自有 OpenAI 兼容接口 / 模型渠道、提示词仓库、定制节点插件、后台管理项。

### 3. 技术支持与咨询（按次 / 包年）

- **适用**：已有部署，需要排障、架构评估、联合方案设计。
- **报价示例**：¥X,XXX / 次，或 ¥X,XXX / 年（包年远程支持）。待确认。

### 4. 团队版 / 云端订阅（规划中，未开放）

- 对应路线图的团队与云端能力（统一账号、云端项目、团队积分与共享项目）。
- **当前未实现，仅在需求中**，不承接预付费或提前售卖。

## 建议提供的信息

- 你的业务场景和预期用户规模。
